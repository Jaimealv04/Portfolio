# Portfolio

This is a modern personal portfolio built with Vite, React, TypeScript, and Framer Motion. It showcases all my personal knowledge and ongoing career.

## Tech Stack

- **Vite** - Lightning fast build tool
- **React 18** - Modern UI library
- **TypeScript** - Type-safe JavaScript
- **Framer Motion** - Beautiful animations and interactions

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

## Features

- ⚡️ Lightning fast with Vite
- 🎨 Beautiful animations with Framer Motion
- 📱 Fully responsive design
- 🌙 Dark/Light mode support
- 🎯 TypeScript for type safety
- ✨ Modern React with hooks
